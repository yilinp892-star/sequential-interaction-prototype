https://yilinp892-star.github.io/sequential-interaction-prototype/

## Appearance panel

The prototype (`docs/`) has a floating, collapsible panel on the left for tuning its look: atmosphere, the four papers, the typewriter body, keys, type and ink, and the fold and drawer. There are five presets: Original, Morning, Night, Old letter and Fresh (pale mint, white paper, soft teal ink). Settings are kept in the browser across reloads. "Reset to defaults" returns to the saved defaults in `docs/js/look.js`. "Copy settings" copies every value so it can be saved as the new defaults.
