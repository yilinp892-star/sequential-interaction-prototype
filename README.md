https://yilinp892-star.github.io/sequential-interaction-prototype/

## Appearance panel

The prototype (`docs/`) has a floating, collapsible panel on the left for tuning its look: atmosphere, the four papers, the typewriter body, keys, type and ink, and the fold and drawer. There are four presets: 原版, 清晨, 深夜 and 旧信. Settings are kept in the browser across reloads. 「恢复默认」 returns to the saved defaults in `docs/js/look.js`. 「复制设置」 copies every value so it can be saved as the new defaults.
