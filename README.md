## Appearance panel

The prototype (`docs/`) has a floating, collapsible panel on the left for tuning its look: atmosphere, the four papers, the typewriter body, keys, type and ink, and the fold and drawer. It opens in a gothic look (near-black, aged parchment, blood-red rules and signature, brass details, blackletter guide text); those saved defaults are the `SAVED` block in `docs/js/look.js`. There are four presets: Original (the first grey look), Morning, Night and Old letter. Settings are kept in the browser across reloads. "Reset to defaults" returns to the saved defaults. "Copy settings" copies every value so it can be saved as the new defaults.
